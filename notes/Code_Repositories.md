## Actively maintained

- **[microsoft/ML-For-Beginners](https://github.com/microsoft/ML-For-Beginners)** - MIT, ~90k stars, the most starred repository tracked here. Note on [[Learning_Resources]].
- **[sacridini/Awesome-Geospatial](https://github.com/sacridini/Awesome-Geospatial)** - CC0-1.0, 5,270 stars, 50+ categories of geospatial tooling. Note on [[Community_Resources]].
- **[awesome-spectral-indices/awesome-spectral-indices](https://github.com/awesome-spectral-indices/awesome-spectral-indices)** - MIT, 1,170 stars, spectral index formulas as machine-readable JSON/CSV with bindings in four languages. Note on [[Remote_Sensing]].
- **[stac-utils/pystac](https://github.com/stac-utils/pystac)** - the reference Python STAC implementation, 455 stars, pushed today. The GitHub API reports the license as unrecognised rather than absent; the project documents itself as Apache-2.0, so check the LICENSE file before assuming either. 82 open issues. Note on [[Python]].
- **[planetlabs/notebooks](https://github.com/planetlabs/notebooks)** - Apache-2.0, 678 stars, Planet Engineering API guides. Note on [[Data]].
- **[buckai-observatory/geoai-datacubes](https://github.com/buckai-observatory/geoai-datacubes)** - MIT, from Ohio State, 26 missions into AI-ready cubes. Note on [[Data]].
- **[satellite-image-deep-learning/annotation](https://github.com/satellite-image-deep-learning/annotation)** - Apache-2.0, catalogue of annotation tools that handle GeoTIFF. Note on [[Data]].
- **[allenai/olmoearth_pretrain](https://github.com/allenai/olmoearth_pretrain)** — "Earth system foundation model data, training, and eval" from AI2. The most starred and most active repo here: 299 stars, 25 open issues, and last pushed the same day this page was built. Ships under the custom OlmoEarth Artifact License, not a standard open license — read the terms before building on it. Note on [[Foundation_Models]].
- **[HarvestStat/HarvestStat-Africa](https://github.com/HarvestStat/HarvestStat-Africa)** — MIT, Jupyter-first, harmonized subnational crop statistics for 33 African countries with an accompanying *Scientific Data* paper. 12 open issues, actively maintained. Note on [[Agriculture]].
- **[msalehsaudi/SentinelLabel](https://github.com/msalehsaudi/SentinelLabel)** — MIT, "a tool for easy geospatial annotation": streams Sentinel-2 from S3, auto-segments into superpixels, hotkey classification, GeoPackage export. 53 stars. Note on [[Data]].
- **[torchgeo/ssl4eo-l](https://github.com/torchgeo/ssl4eo-l)** — MIT, "code to reproduce datasets and experiments from SSL4EO-L paper", split out of TorchGeo. Only 1 star, but it is reproduction code for a NeurIPS 2023 paper rather than a product. Note on [[Foundation_Models]].
- **[montimaj/agribound](https://github.com/montimaj/agribound)** — "An AI-powered field boundary delineation toolkit combining satellite foundation models, embeddings, and global training data for accurate agricultural parcel/field boundary mapping." Apache-2.0, Python, no open issues, docs at [montimaj.github.io/agribound](https://montimaj.github.io/agribound/). Created March 2026 and the newest repo here, so expect churn. Note on [[Agriculture]].
- **[AI-Tianlong/HieraRS](https://github.com/AI-Tianlong/HieraRS)** — reference implementation for the TGRS paper on hierarchical multi-granularity segmentation and cross-domain transfer. No license file, which blocks reuse until one appears. Note on [[Land_Cover]].
- **[google/forest-data-partnership](https://github.com/google/forest-data-partnership)** — MIT, Jupyter-first, holds the versioned TensorFlow commodity models and the Earth Engine model-hosting notebook. Backs the datasets published through [[Google_Earth_Engine]]. Note on [[Forestry]].

## Released and quiet

These are dataset or paper releases rather than living projects; a stale push date is expected, not a warning sign.

- **[MiliLab/S5](https://github.com/MiliLab/S5)** — official code for the AAAI 2026 Oral paper on scalable semi-supervised segmentation. No license file. Note on [[Land_Cover]].
- **[sijieaaa/UAVScenes](https://github.com/sijieaaa/UAVScenes)** — ICCV 2025 release, by far the most starred here (206). License reads as `NOASSERTION`, meaning a custom or unrecognised license file — check terms before reuse. Note on [[Remote_Sensing]].
- **[buyukkanber/vhrv](https://github.com/buyukkanber/vhrv)** — vessel benchmark with pretrained YOLO v5–v12 and R-CNN weights. No SPDX license, and the README restricts use to academic purposes only. Note on [[Remote_Sensing]].
- **[cliffbb/OpenEarthMap-SAR](https://github.com/cliffbb/OpenEarthMap-SAR)** — MIT, dataset for the 2025 IEEE GRSS Data Fusion Contest Track 1. Note on [[Land_Cover]].
- **[swiss-territorial-data-lab/proj-vit](https://github.com/swiss-territorial-data-lab/proj-vit)** — Scale-MAE adapted to 5-band imagery, the companion code for the M3DRS dataset. No license declared. Note on [[Remote_Sensing]].

## Licensing watch

Six of the nineteen cannot be safely reused as-is: HieraRS, VHRV, proj-vit and S5 declare no license at all (default copyright, all rights reserved), while UAVScenes and OlmoEarth ship non-standard ones. PySTAC reports as unrecognised by the GitHub API but documents itself as Apache-2.0, so check its LICENSE file rather than assuming. Everything else carries clear permissive terms: Apache-2.0 (agribound, annotation, planetlabs/notebooks), MIT (forest-data-partnership, OpenEarthMap-SAR, HarvestStat-Africa, SentinelLabel, ssl4eo-l, ML-For-Beginners, awesome-spectral-indices, geoai-datacubes) or CC0-1.0 (Awesome-Geospatial).
